# CARD genome feature modeling

This research prototype turns genome assemblies into CARD RGI-derived features,
joins them with measured antimicrobial susceptibility testing (AST) labels, and
trains a binary resistant/susceptible classifier. Evaluation holds out whole
isolates to prevent rows from the same isolate appearing in both partitions.
It is not validated for clinical treatment decisions.

## Pipeline

1. Provide validated nucleotide FASTA assemblies and a genome manifest.
2. Run the locally installed CARD Resistance Gene Identifier (RGI) for each
   assembly.
3. Convert RGI hits to an isolate-level binary feature matrix. Features retain
   detected AROs, AMR gene families, model types, RGI cutoff/status, and
   reported SNP evidence.
4. Join those features to measured AST labels and evaluate on held-out isolates.

## Project layout

```text
data/
  genomes.csv                       # Input manifest (create this)
  ast_labels.csv                    # Measured phenotype labels (create this)
  genome_antibiotic_features.csv    # Generated by feature extraction
  rgi_results/                      # Per-isolate RGI output
models/
  resistance_model.joblib           # Generated model bundle
src/
  extract_features.py               # FASTA validation, RGI, feature matrix
  train.py                          # AST join, training, grouped evaluation
  train_surveillance.py             # NCBI genotypes + NLM AST training route
requirements.txt
```

## Input formats

Create `data/genomes.csv` with one genome per row:

```csv
isolate_id,organism,fasta_path
iso_001,Escherichia coli,genomes/iso_001.fasta
iso_002,Klebsiella pneumoniae,genomes/iso_002.fasta
```

Relative FASTA paths are resolved from the manifest's directory. FASTA files
must contain one or more non-empty nucleotide records with IUPAC DNA symbols.
Each `isolate_id` must be unique in the manifest.

Create `data/ast_labels.csv` with measured AST results:

```csv
isolate_id,antibiotic,phenotype
iso_001,ampicillin,R
iso_001,ciprofloxacin,S
iso_002,ampicillin,S
```

Only `R` and `S` phenotypes are used; labels are trimmed and case-normalized.
Intermediate or otherwise unsupported labels are excluded and counted in the
training summary. AST rows without a matching genome are excluded and counted
as well. Each isolate-antibiotic pair must occur once.

## Install and run

Install the Python dependencies:

```powershell
python -m pip install -r requirements.txt
```

Install RGI separately using its
[official installation instructions](https://github.com/arpcard/rgi). RGI and
its CARD reference data are external prerequisites, not pip requirements.
Ensure the `rgi` executable and its database are available in the environment
where the pipeline runs.

Run feature extraction:

```powershell
python src/extract_features.py `
  --manifest data/genomes.csv `
  --output data/genome_antibiotic_features.csv `
  --rgi-output-dir data/rgi_results
```

If you have the NCBI `isolates.csv` metadata file and the NLM AST export instead
of FASTA files, those provide a separate route using the already reported AMR
genotypes. Put the files in `data/` or pass their paths explicitly:

```powershell
python src/train_surveillance.py `
  --isolates data/isolates.csv `
  --ast data/NLM.csv `
  --output models/nlm_resistance_model.joblib
```

This route joins on BioSample, uses organism/antibiotic and the NCBI
`AMR genotypes` field as features, and uses only the `Resistance phenotype`
column for the target. It does not rerun RGI on assemblies. Unsupported AST
categories are excluded; conflicting R/S results for the same
BioSample-antibiotic pair and missing/conflicting genotype records are excluded.
## Try a prediction

Use the NCBI organism group, antibiotic name, and genotype call format from
`isolates.csv`:

```powershell
python src/predict_surveillance.py `
  --organism "Salmonella enterica" `
  --antibiotic ciprofloxacin `
  --genotypes "gyrA_D87Y=POINT,parC_S80I=POINT"
```

For an isolate with no reported AMR calls, omit `--genotypes`. The output gives
the predicted `R`/`S` label and model probabilities. This classifier was trained
on the NCBI `AMR genotypes` field, so supply genotype strings in the same
`gene=call` format. Unknown organisms, antibiotics, or gene calls are allowed,
but are not learned categories for this saved model and can reduce prediction
reliability.

## Interactive 3D web app

Start the local API and frontend with the project's Python environment:

```powershell
.\.venv\Scripts\Activate.ps1
python src/server.py
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000). The interface checks the
API/model health, loads the trained antibiotic options, and displays prediction
warnings. Choose an antibiotic, then either enter one organism and optional AMR
genotype calls in the **Manual isolate input** form or upload an NCBI
`isolates.csv` export and select **Analyze isolates**. The browser streams the
CSV and predicts up to 5,000 isolates per run; the file is not saved by the
server. The animated DNA helix uses Three.js from jsDelivr, so the visualization
needs an internet connection.

The file must include `#Organism group` and `AMR genotypes` columns. Predictions
use these genotype calls plus the selected antibiotic. Raw FASTA files are not
analyzed by this interface. Check API connectivity at
`http://127.0.0.1:8000/api/health` and available model options at
`http://127.0.0.1:8000/api/options`.

Evaluation holds out complete SNP clusters, falling back to BioSample when the
cluster is unavailable, to reduce leakage between related isolates. The saved
bundle includes the fitted sparse feature encoder and logistic-regression
model. The script reports metrics on the held-out clusters, then fits the saved
deployment model on all eligible joined rows.

Join features to AST labels, train, and evaluate:

```powershell
python src/train.py `
  --features data/genome_antibiotic_features.csv `
  --ast data/ast_labels.csv `
  --output models/resistance_model.joblib
```

Both scripts accept `--help` for configurable paths and column names. The RGI
extraction command uses contig input mode. RGI failure, invalid FASTA, missing
required RGI output fields, duplicate isolate-antibiotic AST pairs, and a group
split without both classes in train and test stop with an explicit error.

The feature matrix includes isolate and organism metadata plus binary
`gene__`, `family__`, `model__`, `status__`, and `mutation__` columns. During
training, antibiotic and organism are one-hot encoded; the genomic columns are
passed to a class-balanced random forest. The saved model bundle includes the
fitted preprocessing/model pipeline, feature names, target classes, metrics,
split details, and scikit-learn version.

Review CARD's current terms and licensing requirements before using RGI or CARD
data, especially for commercial use.
